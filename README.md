# User Inyerface UI Automation

UI-автотесты для учебного сайта [userinyerface.com](https://userinyerface.com/) — игры с намеренно неудобным интерфейсом, на которой отрабатывают поиск элементов, ожидания и работу с нестандартными формами.

## Стек

* Java 25, Maven
* TestNG
* Aquality Selenium (обёртка над Selenium WebDriver)
* JavaFaker
* Паттерн Page Object

## Что проверяют тесты

* `RandomDataTest` — прохождение регистрации: ввод случайных email и пароля, принятие условий, выбор случайных интересов, загрузка аватара и переход на карточку Personal Details.
* `AcceptCookiesTest` — форма cookies появляется и закрывается после принятия.
* `HideHelpFormTest` — форма помощи скрывается по нажатию кнопки.
* `TimerTest` — таймер на странице регистрации стартует с `00:00:00`.

## Архитектура проекта

Проект построен на паттерне Page Object. Логика фреймворка находится в `main`, тестовые сценарии — в `test`.

1. `main/java/pages` — классы страниц и форм, сгруппированные по назначению:
   * `datafill` — страницы регистрации (`EmailPage`, `ImagePage`, `PersonalDetailsPage`).
   * `cookies`, `help`, `timer` — всплывающие и сквозные формы.
   * `MainPage` — главная страница.
2. `main/java/utils` — утилиты: генератор случайных тестовых данных, выбор случайных чисел, загрузка файла через системное окно (`RobotUtils`).
3. `test/java/base` — базовый класс `BaseTest`, который перед каждым тестом открывает браузер на главной странице, а после теста закрывает его.
4. `test/java/tests` — тестовые сценарии.

## Конфигурация и данные

Все настройки и тестовые данные лежат в `src/test/resources`:

* `config.json` — параметры тестов (базовый URL, количество интересов, ожидаемое время таймера, путь к изображению).
* `settings.json` — настройки Aquality Selenium (браузер и таймауты).
* `images.jpg` — изображение для проверки загрузки аватара.

## Запуск тестов

Требуется установленный JDK 25 и Maven.

**Через IDE (IntelliJ IDEA)**

1. Откройте папку проекта, в которой лежит `pom.xml`.
2. Дождитесь импорта Maven-зависимостей и индексации.
3. Откройте нужный класс в `src/test/java/tests` и нажмите кнопку Run рядом с названием класса или метода.

**Через терминал**

Перейдите в папку проекта, в которой лежит `pom.xml`, и выполните:

```bash
mvn clean test
```

Если при первом запуске скачивание зависимостей зависло, прервите выполнение и запустите с принудительным обновлением:

```bash
mvn clean test -U
```
